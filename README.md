# 非遺音樂地理誌（Music Map Project）

以「地圖」為載體的中國民間／非遺音樂互動網頁。點擊地圖上的金色標記，即可閱讀該地區的音樂介紹、查看採集現場照片，並直接播放對應的音訊檔案。

本專案為純前端靜態網頁，不需建置、不需後端，直接用瀏覽器開啟 `index.html` 即可運行。

---

## 功能特色

- **互動地圖**：以 Leaflet 為底層，使用高德地圖圖磚（中文地名、中國大陸連線穩定）。
- **三種底圖切換**：深色／街道／衛星，可在右上角圖層控制項自由切換。
- **7 個音樂標記**：覆蓋澳門、台灣、潮汕、廣州、四川、揭陽、泉州等地。
- **資訊框多媒體**：每個標記彈出視窗包含樂曲介紹、採集／樂器照片與圖說（含授權出處）。
- **音訊播放**：內嵌播放器即點即聽，單一播放防呆（同時只播一首），關閉資訊框自動暫停。
- **開場自動縮放**：載入時自動 `fitBounds`，讓 7 個標記一次全部進入畫面。
- **深色主題**：整體採用深色視覺，襯托金色標記與播放光暈，風格沉靜典雅。
- **字型優化**：載入 Noto Serif TC 明體，並以本機明體／楷體作為後備，離線也不影響閱讀。

## 專案結構

```
music-map-project/
├── index.html              # 主程式：地圖、資料庫、標記、播放邏輯
├── assets/
│   ├── *.mp3               # 7 首樂曲音訊檔
│   └── img/
│       └── *.jpg           # 各地音樂採集／樂器照片
├── vendor/
│   └── leaflet/            # Leaflet 本機版（leaflet.js / leaflet.css / images）
└── README.md
```

> 註：Leaflet 由 CDN 改為本機 `vendor/` 版本，避免外部 CDN 不穩定導致地圖載不出來。

## 使用方式

1. 將專案下載或 clone 到本機。
2. 直接以瀏覽器開啟 `index.html`。
3. 點擊地圖上的金色標記，閱讀介紹並播放音樂。

### 本機預覽（可選）

若遇到瀏覽器對本機檔案（`file://`）的限制，可起一個簡易伺服器：

```bash
# Python 3
python -m http.server 8000

# 或 Node.js
npx serve .
```

再開啟 <http://localhost:8000>。

## 技術要點

- **座標校正**：資料庫原始座標為 WGS-84，程式在繪製前統一換算為 GCJ-02（高德圖磚使用加密座標），避免標記偏移 300～600 公尺。
- **檔名統一小寫**：音訊檔名一律小寫，避免 Linux 主機（含 GitHub Pages）嚴格區分大小寫導致 404。
- **單一播放防呆**：透過記錄目前播放的標記，確保同時只有一首樂曲播放。
